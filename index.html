      嘉Jaykou动效工作台 / 使用方式
      
    

    

      
从灵感到成片 · 三步

      
不只是看动效，
而是把动效调成你的。

      
    
        
  1. 1 选
    点右上角 动效库（或按 B）：库内动效按 10 个大类收纳，顶部一排分类快捷筛选点一下就切，点大类展开细类与全部动效清单，点清单里的单元即进入工作台；随机灵感 骰子一键跳转，/ 聚焦搜索。
    2. 
        
  2. 2 调
    右侧 参数 面板改文案、颜色、速度——每改一处画面立刻更新；配色背景 里一键换主题或改随机种子，同一个动效变成全新样子。
    3. 
        
  3. 3 拿
    右侧 导出 面板按用途选：视频用 MP4、公众号用 GIF、封面上用 PNG、嵌网站用单文件 HTML / React 组件 / iframe。
    4. 
      


      
怎么把动效变成自己的 · 按需求选

      

        
你的目的怎么做一致度

        
要一个一模一样的动效放进自己项目导出 → 复制 draw 源码 或 导出 → 复制/下载单文件 HTML100%

        
让 AI 帮我把它改造/扩展成新版本参数 面板底部 → 选 源码版 → 复制移植提示词≈100%

        
只有一句想法，想让 AI 从零写一个选 描述版 → 复制提示词接近

        
要一段能跑的代码起点给 AI 补完选 骨架版 → 复制提示词中等

      

      
关键提醒：AI 提示词不是"复制粘贴就能 100% 一样"——模型会重写实现，噪声、缓动、线条细节都会变。要原样复刻，请走源码通道（复制 draw 源码 / 单文件 HTML）；提示词的定位是"让 AI 照着我们的思路写，观感一致"。

      
想连续播放多个动效？调好后点 + 加入当前动效 组成场景序列，可整条录制导出。
