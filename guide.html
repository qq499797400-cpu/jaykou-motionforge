01 三分钟上手

挑一个动效

点右上角 动效库（或按 B）。顶部一排是分类快捷筛选，点一下即筛；往下是卡片墙，鼠标悬停卡片会实时预览。也可以用顶部搜索框直接搜关键词（如 标题、粒子、K线）。找到喜欢的，点卡片进入工作台。

调成你要的样子

右侧 参数 面板改文案、颜色、速度、数量……每改一处画面立刻刷新。想换整体气质就去 配色背景：一键换主题预设，或拖动 随机种子 —— 同一个动效换个种子就是另一种形态，但拖动时间轴画面不会乱跳。

按用途导出

右侧 导出 面板：剪进视频用 MP4、公众号/小红书用 GIF、做封面用 PNG、嵌网站用 单文件 HTML / React 组件 / iframe。想串成一条片，就点 + 加入当前动效 组成场景序列，再整条录制。

02 核心：三种"拿到动效"的方式

很多人第一反应是"把那段提示词复制给 AI，就能做出一样的"——这条路走不通。原因很简单：动效真正的样子来自 draw() 函数里几百行数学计算（噪声、缓动曲线、确定性随机种子、线条抖动参数）。提示词只是描述，AI 会用自己的方式重写一遍，细节必然不同：同样的"流星雨"，AI 写出来的粒子数量、拖尾长度、随机分布都不一样。想一致，只有把实现本身拿走。

你的目的怎么做一致度
要一个一模一样的动效，放进自己项目导出 → 复制 draw 源码（只拿绘制函数）或 复制单文件 HTML 源码（连运行时一起）100%
让 AI 把它改造成新版本（换配色逻辑/加交互）参数 面板底部 → 选 源码版 → 复制移植提示词≈100%
只有一句想法，让 AI 从零写一个类似风格选 描述版 → 复制提示词接近
要一段能跑的骨架代码让 AI 补完选 骨架版 → 复制提示词中等
一句话记住：要"一样"用源码（导出面板里的两个复制/下载），要"灵感"用提示词。提示词的价值是让 AI 照着我们的思路写，而不是复刻。

提示词三种模式，分别在做什么

推荐

源码版

提示词里会附带本站已验证的完整实现代码，并明确要求 AI 原样移植、不要重写。适合：让 AI 帮你把它接进自己的项目、改成模块、换画布尺寸。

  • 给出参数声明 + 完整 draw() 实现
  • 附上运行时接口说明（U 对象）
  • 明确禁止重新设计画面

一致度：≈100%（AI 只做适配，不改逻辑）

描述版

只给文字描述 + 风格标签。适合：你只有个模糊想法，想让 AI 自由发挥一个同风格的东西。

  • 动效名称、分类、描述、风格标签
  • 画布与配色信息
  • 不含任何实现代码

一致度：接近（细节由模型决定）

骨架版

给参数 + 渲染循环骨架，让 AI 填实现。适合：你要一段结构规范、能直接跑的代码起点。

  • 参数对象、确定性随机、循环骨架
  • draw 函数体留空待补
  • 标注了实现约束（可 seek、可循环）

一致度：中等（结构一致，画面靠 AI）

03 源码通道怎么用

A. 复制 draw 源码 —— 只需要绘制逻辑

适合你已经有自己的 Canvas 项目。点 导出 → 复制 draw 源码，拿到的是：

  • const PARAMS = {...} —— 当前所有参数的取值
  • const draw = function (ctx, t, P, U) {...} —— 完整绘制函数

自己项目里的调用方式：

ctx.save(); draw(ctx, t, PARAMS, U); ctx.restore();

B. 复制/下载单文件 HTML —— 连运行时一起

点 导出 → 复制单文件 HTML 源码（或 单文件 HTML 下载）。得到的是一个自包含网页：内联运行时 + 该动效源码 + 当前参数。粘贴保存成 .html 双击就播，效果与工作台里 100% 一致，无需任何依赖。想嵌到网站就放进 iframe 或直接当页面。

C. React 组件 / iframe 嵌入

  • 复制 React 组件：粘进 React 项目即可用，无第三方依赖。
  • 复制嵌入代码：一行 iframe，适合快速挂到任意页面。

04 参数、配色与种子

  • 参数面板：每个动效的参数都不一样，改了立刻所见即所得。底部「恢复默认 / 随机化」可以一键重来或撞灵感。
  • 配色背景：6 组主题预设 + 主色/辅色/文字色/背景色自定义；背景模式有渐变光晕、径向聚焦、网格、纯色、透明（透明适合当叠加层）。
  • 随机种子：所有"随机"元素都由种子决定。同一个动效，种子 7 和种子 42 是两个样子；但拖动时间轴不会乱跳——这是可复现渲染的好处。
  • 画布比例：顶栏可切 16:9 / 9:16 / 1:1 等，导出会跟随。

05 场景序列：把多个动效串成一条片

  1. 调好一个动效 → 点 + 加入当前动效，它会作为一段进入序列。
  2. 再挑下一个动效调好 → 继续加入，按需调整每段时长。
  3. 点 播放全序列 预览整条片；确认后到 导出 面板点 录制裁剪好的整条序列，直接导出一条 MP4。

06 常见问题

为什么我把提示词复制给 AI，做出来的不一样？

因为提示词是描述不是代码。动效的真实形态藏在几百行绘制逻辑里（粒子分布、噪声频率、缓动曲线、抖动幅度），AI 会按自己的理解重写。要一致请走源码通道：导出 → 复制 draw 源码。如果你是要让 AI 帮你改造（而不是复刻），用源码版提示词，它会带上完整实现并要求 AI 只做移植。

导出的 GIF 有点糊/文件很大？

到 导出 面板调整 GIF 宽度与帧率：宽度 640 + 12fps 是清晰度与体积的平衡点；只做表情包或小图可降到 480/8fps。追求画质请改用 MP4。

录制 MP4 没反应 / 只有 WebM？

MP4 录制依赖浏览器的 H.264 编码能力（Chrome / Edge / Safari 支持较好）。若浏览器不支持会自动回退 WebM。建议用最新版 Chrome 录制；WebM 可直接上传视频号或在剪映里转码。

怎么把这个工作台分享给别人？

直接把这个网址发给他即可，无需登录。想让他打开就看到你调好的某个动效，点 分享链接，链接里带着完整参数，对方打开就是同一个画面。

这些动效可以商用吗？

本工作台动效为原创实现，导出的源码/视频/GIF 可直接用于你的项目与商业内容。建议按平台要求自行标注素材来源。
